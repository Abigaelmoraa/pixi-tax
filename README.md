# Pixi Tax Management System

## Project Info

This is the Pixi Tax Management System, a platform for managing tax records, client data, and financial operations efficiently.

## How to Edit the Code

You can edit this project locally using your preferred IDE.  

### Prerequisites

Make sure you have **Node.js** and **npm** installed. You can install Node.js using [nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

### Steps to Run Locally

```sh
# Step 1: Clone the repository
git clone <YOUR_GIT_URL>

# Step 2: Navigate to the project directory
cd pixi-tax-management

# Step 3: Install dependencies
npm install

# Step 4: Start the development server
npm run dev
